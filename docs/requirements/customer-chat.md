# 客服对话系统 — 需求

## 目标

面向访客与客服的在线对话 Web 系统：访客登录后能找到对应客服并实时对话；一名客服可同时接待多名访客；对话在断线、重试、重连场景下不丢消息、不重复、不乱序。

## 需求点

### R1 登录
- 访客可注册并登录，登录后才能使用对话功能。
- 客服使用预置账号登录；不开放客服自助注册。
- 未登录访问聊天页面跳转登录页；接口按角色鉴权，访客不能调用客服接口。

### R2 找到对应客服
- 访客登录后不展示客服或好友列表，由系统自动匹配一位在线且有余量的客服并直接进入会话。
- 匹配不到时明确提示，不静默进入无人接待状态。
- 同一访客同一时间只能有一个进行中的会话；换客服需先结束当前会话。

### R3 客服 1 对多
- 每个会话是一对一（一名访客与一名客服）。
- 一名客服可同时持有多个进行中的会话，受并发上限约束（默认 5）。
- 客服工作台按访客列人，同一访客只显示一行（优先进行中的会话），可切换会话回复。

### R4 对话可靠性
- 消息先持久化成功再推送，不出现"客户端收到但服务端无记录"。
- 每个会话内消息序号由服务端分配且单调递增；客户端按序号渲染并检测缺口。
- 客户端重试携带消息 ID，重复提交不产生重复消息。
- 断线重连后按最后已知序号补齐缺失消息。
- 消息状态可区分：已发送、已送达、已读。

### R5 工单记录
- 每次会话自动生成一张工单，工单号形如 `T-YYYYMMDD-NNNNN`。
- 客服可在「工单记录」查看自己会话的完整聊天记录（按时间正序）。
- 工单支持导出 TXT 与 CSV。
- 工单仅对服务该会话的客服可见；访客不可访问。

### R6 数据保留
- 聊天记录自每条消息发送时间起保留 30 天，到期逐条删除（可通过 `Retention:Days` 调整）。
- 工单与会话记录保留；进行中的会话同样按消息发送时间逐条清理。
- 浏览器本地缓存按同样的 30 天策略清理。

### R7 工单转派
- 客服可把自己正在服务的进行中工单转派给另一名客服，转派后由目标客服接续服务。
- 转派仅限进行中的工单；已结束的工单不可转派。
- 转派对象必须是客服账号，且不能是自己；目标客服活跃会话已达到上限时拒绝转派并说明原因。
- 转派后原客服不再看到该工单，也收不到该会话的新消息；目标客服的工单列表与工作台即时出现该会话。
- 访客端即时看到客服变更的提示，会话继续，不需要重新发起。
- 每次转派记录原客服、目标客服、时间与可选备注，可在工单详情查看。

### R8 管理中台
- 管理员用独立账号登录管理后台；访客与客服无权访问后台页面与接口。
- 管理员可新增客服账号、修改展示名与并发上限、重置密码、启用或停用账号。
- 停用的客服不能登录；已登录的停用客服收到登出通知并回到登录页。
- 管理员可跨客服查看全部会话与工单，并查看任意工单的聊天记录与转派台账。
- 管理员可把任意进行中的工单强制转派给指定客服；台账同时记录原客服与操作的管理员。
- 后台界面包含：仪表盘、客服管理、会话总览、工单总览。

### R9 数据统计
- 管理员在仪表盘查看概览：会话数、消息数、工单数、转派次数、在线客服数、进行中工单、平均首响。
- 近 N 天（默认 14）按日趋势：新会话、消息、工单，含 0 值日。
- 按客服维度：接待会话数、消息数、平均首响、当前活跃会话。
- 首响口径：会话内首条访客消息到首条客服回复的时长；无客服回复的会话不计入均值，样本数单独给出。

### R10 客服桌面客户端
- 提供 macOS 桌面客户端（Electron），加载客服端页面，后端地址可在客户端内配置（默认 `http://localhost:5180`）。
- 托盘常驻：显示/隐藏窗口与退出。
- 新消息、被转派、账号停用时弹系统通知；点击通知聚焦窗口。

### R11 富文本消息
- 客服与访客使用所见即所得编辑器，输入框内即时显示格式：粗体、斜体、删除线、行内代码、代码块、引用、列表、链接、表情。
- 消息按格式渲染；发送 HTML 或脚本内容时按文本显示，不得执行。
- 会话列表、工单列表与后台表格的摘要显示纯文本（无格式符号）。
- 富文本源文计入单条消息 2000 字上限；导出 TXT/CSV 保留源文。

### R12 图片与附件消息
- 客服与访客均可上传图片与附件，输入框支持工具栏选图、粘贴图片与拖拽图片。
- 支持类型：png/jpg/jpeg/gif/webp/pdf/txt/csv/zip/doc/docx/xls/xlsx；单文件不超过 10 MB。
- 图片在消息中内联显示；其它文件以可下载链接显示，下载时保留原文件名。
- 上传需要登录；类型、大小不合规或图片内容与扩展名不符时明确拒绝。
- 文件以随机名存储，读取地址不可枚举。

## 验收标准

- 后端构建无错误，自动化测试覆盖：并发发送序号单调、幂等重发、客服并发上限、增量补拉、鉴权失败路径。
- 启动后可完成完整业务闭环：访客登录 → 选择/分配客服 → 双向收发 → 回执状态正确 → 刷新或重连后历史完整。
- 未登录访问受保护接口返回 401，访客调用客服接口返回 403。
- 转派闭环：客服 A 把进行中工单转给客服 B 后，A 的工单列表不再含该工单、B 可继续接待，访客端显示新客服。
- 中台鉴权：访客与客服调用 `/api/admin/*` 返回 403；管理员可新增客服并用新账号登录，停用后该账号登录返回 403。
- 富文本：发送带格式的消息后对端按格式渲染；发送 `<script>` 或 `onerror` 属性时页面不执行脚本。
- 图片与附件：粘贴图片后消息内联显示；附件可下载且保留原文件名；超过 10 MB 或类型不允许时拒绝。

## 边界（本轮不做）

- 密码找回、刷新 token、邮箱验证、多设备会话管理。
- 多实例集群与 Redis 背板（当前为单实例部署）。
- 消息撤回、编辑、图片与文件消息、排队、客服账号管理后台。
